# 归档/经验（冷层）

> 经验笔记的**冷层**：`last-used` 为空或距今 >2 年的笔记由预检流程移入此处。保留全文，**退出预检扫描范围**；需要时仍可手动检索（Obsidian 全文搜索）。

## 规则（与 [[项目驱动知识库模式]] 同步）

- 移入条件：`last-used` 缺失或距今 >2 年（预检扫描时发现即移入，见 [[项目预检模板]] 读取闸门 ⑥）
- 移入方式：`mv 经验/<笔记>.md 归档/经验/`（不改内容，仅退层）
- 回升条件：人工检索命中且仍相关 → 补 `last-used` 后移回 `经验/`
