# photo-abstract-editorial 照片抽象编辑规范（蒸馏）

> 来源：github 下载 skill `photo-abstract-editorial`（SKILL.md + references 中英提示词 + 5 张示例图），2026-08-09 精读蒸馏。核心：把一张照片变成"原照片区域 + 抽象记忆面板 + 诗意英文标题"的竖向编辑作品。

## 一句话定义

保留照片本身 + 从照片关系推导出的极简抽象面板——不是滤镜、不是风格迁移、不是照片矢量化、不是缩略图描摹。

## 方法链

`DECONSTRUCT → SELECTIVE PRESERVATION → ABSTRACT/DISTILL → RECONSTRUCT`

1. 找出照片中最重要的 3–6 个空间事实（主体关系、尺度、轴、方向、间隔、遮挡、层次、节奏、光、色彩角色、留白）
2. 判断哪些来自主体质量、哪些来自结构轴/节奏/非对称/色彩层级
3. 删掉表面纹理、透视细节、背景杂讯
4. 用最少的标记重组被保留的关系
5. 验收标准：第一眼是极简抽象构成，第二眼才联想到这张特定照片

## 输入图片双重角色

- **摄影区域**（上方/主要区域）：只允许等比缩放或轻微裁切，**绝不重画/替换/扩展/修饰/加滤镜**
- **抽象面板信息来源**：只从照片分析空间/色彩/结构关系，不引入任何外部元素

## 抽象程度分级（按主体自适应，"最低必要辨识度"）

| 主体 | 处理 |
|---|---|
| 普通场景/自然/光影/水面/人群 | 只保留方向、密度、间隔、层级、运动、色彩关系，不保留完整轮廓 |
| 标志性建筑 | 保留 1–3 个身份特征（外轮廓/负空间/檐线/塔身收分/拱洞/尖顶），禁窗户砖石栏杆花纹 |
| 有机群体（气球/树冠/云/灯光） | 重叠柔和色块表达密度与上升扩散，不画内部图案 |
| 人群 | 每人一个连续不规则短竖墨点或微收分色块，头肩一体，不画头/四肢/面孔/衣服 |
| 栏杆/道路/地平线/水岸 | 压成 1–2 条细水平轴 + 少量不规则中断 |
| 小物件（铃铛/灯笼） | 只留 2–3 个平面标记，靠比例位置辨识 |

## 标记系统

- **1 个主要家族**：平面/微有机色块、柔和圆形或不规则质量、弧形/锥形笔触、连续短条/层叠色带、简化建筑质量
- **≤2 个辅助家族**：细线/结构轴、短竖条/孤立小点/微型轮廓、克制人影墨点、少量重复节奏
- 每个标记必须能对应原照片一个事实；**禁止无来源装饰/对称/图案**
- 避免规则化间距：相邻标记要有轻微尺度差、位置差、停顿（观察所得节奏，不是信息图表）

## 拼接比例（自适应，不机械对半）

- 横向照片：摄影区 38%–52% / 面板 48%–62%
- 纵向建筑人物：摄影区 55%–68% / 面板 32%–45%
- 方形/重心均衡：摄影区 48%–58% / 面板 42%–52%
- 允许 ±8% 浮动；不强制固定画布比例；照片与面板**干净平面衔接**（禁撕纸/相框/投影/胶带/样机效果）

## 抽象面板版式

- 背景：均匀连续中性象牙色 `#F3F0E8`（禁渐变/纹理/颗粒/水彩底纹/噪点/污渍/扫描痕迹）
- 母题：占面板宽 30%–42%，高 ≤28%–34%，留白 65%–80%；细长地平线类可宽至 45%–68%（保持低矮）；不要为凑百分比缩成通用小图标

## 色彩系统（只从照片提取，降饱和减数量）

- 1 主色 + 1 深色结构色 + 1 浅/中性色 + **≤2 个小面积强调色**（必须来自照片真实颜色）
- 禁霓虹色、无来源互补色、多个竞争强调色

> 注：与 vision skill `postcard.js` 的三色卡采样（主色/深色结构色/浅色中性色）**同构**——迁移可直接复用该逻辑。

## 标题命名（英文 2–5 词，信达雅）

- 命名方向：光/时间进入空间、两主体关系对话、短暂出现/漂浮/远去/停顿、从色彩/结构轴/运动提炼的隐喻、原创复合词+简短说明
- **禁**：旅游宣传式、地点介绍、摄影术语、空泛 "Memory/Dream/Moment"、与事实无关的宏大叙事
- 副标题仅当新增语义层才加（3–7 词），否则只一个主标题

## 标题排版

- 只放象牙面板内（母题下方/侧边），左下对齐（母题偏右时）或底部居中（母题居中对称时）；**禁放照片区/母题内/右下角/画布边缘**
- 衬线字体：建筑结构题材→稳重书籍衬线；光影自然→人文细衬线；副标题→小号斜体衬线
- 禁商业粗体/无衬线广告字体/卡通/夸张手写
- 标题色：照片中较深克制的颜色（深蓝灰/暗绿/酒红/深紫/炭灰），**不默认纯黑**，不用最鲜艳强调色

## CLEAN 模式（气氛来源）

气氛只能来自：留白、距离、停顿、非对称、尺度差、有限标记、克制配色。禁一切材质噪点。

## 输出限制

只输出一张成品 + 最终主标题（可选副标题）。禁任何额外文字/数字/日期/色卡/图例/签名/logo/水印。

## 与 vision skill 的关系（迁移评估）

- 哲学一致：vision skill 明信片/ZINE 海报已是"原图保留 + 程序化拼版"路线，本规范同路线，**不需要图生图模型**，程序化拼版即可实现（照片像素级保留是硬要求）
- 复用点：`postcard.js` 三色卡采样（色彩系统同构）、程序化拼版骨架；需新增：抽象母题生成（可用 `vision.js --generate` 文生图出母题图案，或矢量绘制）、自适应比例、标题排版规则
- 触发差异：本规范强调"面板只从照片关系推导"，与 ZINE 海报的"单一视觉事件"理念互补
- 落地建议：若迁移进 vision skill，按 ZINE 海报先例——SKILL.md 简述 + references/ 存全规范 + 质量门（VL 复查不变量）
