# finesse-ui 提示词速查卡

> 这个 skill 帮你生成**不廉价**的界面。你只需**描述清楚要什么**，不需要懂设计。
> 它内部自动完成：判断页面类型 → 套设计语言 → 反 AI 味检查。

---

## 一、提示词四要素

```
[1 页面类型] + [2 给谁/干什么] + [3 风格锚点] + [4 内容素材]
```

| 要素 | 说明 | 例子 |
|---|---|---|
| ① 页面类型 | 决定 register（品牌页 / 产品页 / 商品页） | 落地页 / 仪表盘 / 管理后台 / 商品详情页 |
| ② 给谁、干什么 | 给人**看**的 → 炫酷；给人**操作**的 → 清晰好用 | "给投资人看的" / "销售每天录数据的后台" |
| ③ 风格锚点 | **最有效的信号：提一个具体品牌** | "像 Linear 那样"、"Airbnb 风格"、"Nike 的张扬感" |
| ④ 内容素材 | 真实文案 / 数据 / 功能清单 | "指标有：营收、DAU、转化率" |

---

## 二、模板

**好：**
```
帮我做一个 SaaS 数据仪表盘，给产品经理每周看。
风格像 Linear（深色、克制）。
包含：营收趋势图、转化漏斗、最近 10 条用户动态。
数据我自己填，图表先按示例数据来。
```

**坏：** "做个好看的后台页面。"
→ 没说给谁用、没风格锚点，容易产出千篇一律的蓝色仪表盘。

## 三、三个使用技巧

1. **提品牌最有效**：`/finesse match linear` 或 "做成 Linear 那种"
   → 直接加载该品牌的设计规范文件当模板，效果最稳。
   → 内置品牌库：Linear、Notion、Stripe、Airbnb、Apple、Claude、Nike、Spotify、Vercel 等 70+。

2. **先确认方向再写码**：skill 会先给一句 Design Read（设计方案），**看到后说"可以"再继续**；不满意当场改。

3. **不满意用动词命令迭代，不用重来**：

| 命令 | 场景 |
|---|---|
| `bolder` | 太平淡，要更炫 |
| `quieter` | 太花哨，要更克制 |
| `soul` | 感觉普通 / 不像品牌 → 换风格 |
| `animate` | 想换 / 加动画 |
| `densify` | 内容太挤或太松 |
| `audit` | 只检查质量，不改代码 |
| `redesign` | 整体改造 |

## 四、常见页面类型 → 一句话要点

| 你说 | 它默认怎么处理 |
|---|---|
| 落地页 / 品牌页 | 视觉优先：真实的 WebGL/动画引擎 + 独特个性 |
| 仪表盘 / 分析页 | 清晰优先：密度、表格、图表，克制不炫技 |
| 管理后台 / 工作台 | 流程优先：向导式、可完成、别让用户卡在中间 |
| 商品页 (PDP/PLP) | 单商品→品牌感；多商品→筛选/对比优先 |

---

## 五、默认清单（写出好页面的底层规则）

- 不用纯黑纯白，中性色都带一点品牌色相
- 一个页面只用**一个主色**，不漂移
- 不用渐变文字、玻璃拟态、AI 紫光等廉价套路
- 数字必须是真实的，不能编造（92%、4.1× 这类要谨慎）
- 动画必须有理由，且有"减少动态"降级
