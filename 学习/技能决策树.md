## 🧭 主流程：从想法到交付

| 处境 | 操作 |
| --- | --- |
| 有代码库，想法模糊 | /grill-with-docs（面试式澄清，留下 CONTEXT.md） |
| 想法清晰，小改动 | /implement（直接构建） |
| 想法清晰，多 session | /to-spec → /to-tickets → 逐 ticket /implement |
| 需要先试再定 | /prototype（一次性验证代码） |
