# 覆盖率数字必须带口径声明

## 症状
架构加深批次声称「覆盖率 94%」，收尾审计实测含 tests 文件 93%、排除 tests 86%——声称值未复现，需回查口径才知 94% = 生产模块范围（`--cov=app --cov=kkrb_client ...`）。

## 根因
`pytest --cov` 的统计范围由参数决定：含 tests 文件本身 / 排除 / 只测生产模块，三口径数值不同。汇报时只给数字不给范围 = 不可复现。

## 代价
审计阶段对不上数字，多一轮验证往返；跨会话/跨工具数字打架时无法裁决哪个对。

## 教训
覆盖率汇报必须带口径：`--cov` 范围（生产模块清单 or 全库）、是否含 tests。文档与汇报统一口径，否则数字是噪音。

## 防复发
- [x] 已落实：本项目固定口径 = 生产模块 11 个（app + kkrb_client + settings_store + data_store + account_store + calculator + json_file + signals + formatting + presentation + config），DEV_LOG 记录时带口径
- 汇报覆盖率一律附 `--cov` 命令
