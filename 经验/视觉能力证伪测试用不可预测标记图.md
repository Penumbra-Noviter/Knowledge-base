# 视觉能力证伪测试：用不可预测标记图

## 症状
用自然图片验证视觉模型时无法仲裁：两个模型描述矛盾（一个说"民国女子捧灯笼"，一个说"卡通小鸡"），没有 ground truth 判断谁对；且模型会基于文件名/提示词编造看似合理的内容。

## 方法
生成合成图：纯色背景 + 粗体随机字符（如 `QC-8731`），图中唯一内容就是文字，模型不可能猜中。
- 正确逐字读出标记 → 真读图（可佐证 API usage 的 `image_tokens`）
- 编造画面 / 断言"没有文字" → 图像未送达模型
- 两个独立 API 的模型描述一致 → 交叉验证基准

## 教训
能力验证必须构造"猜不到"的 ground truth，不能拿自然图"看描述像不像"；顺带发现：模型收到"查看图片"指令但实际无图时，倾向于编造而非承认看不见。
