# 多页面应用：数据加载挂 showEvent + 一次性守卫（懒加载）

## 症状
CraftingPage 首次切换到该页不自动加载数据，需手动点刷新；反过来，若把加载放在构造时，应用启动即发网络请求（白请求 + 启动变慢）。「页面创建」与「页面可见」被混为一谈。

## 根因
QStackedWidget 的页面在构造时就创建，但「可见」发生在首次切换时。构造期加载 → 启动白请求；切换期不加载 → 用户首见空页。两个错误方向都源自同一个混淆。

## 教训
**多页面应用的数据加载挂 `showEvent` + `_loaded_once` 守卫**：首次显示触发加载，之后手动刷新。懒加载的语义是「首次可见才加载」，不是「创建时加载」也不是「每次可见都加载」。
