# 视觉模型漏判短暂弹出 UI 须交叉验证

## 症状
点击「测试连接」按钮后截图识别，qwen 视觉模型回答「没看到 SnackBar / 按钮没生效」；但 SnackBar 实际已弹出（浅色条 #F1ECE4 + 文本像素 + 「测试连接跳过(claude): 未提供 API Key」日志）。

## 根因
SnackBar/Toast 生命期只有秒级。视觉模型对瞬时状态敏感度不足——即便截图时机正确（帧里确实有 SnackBar），模型也可能漏判；识别「没看到」不等于对象不存在。

## 代价
一次误报「按钮未生效」，不验证会把人引向错误排查方向（怀疑点击逻辑）。本次靠双重非视觉证据纠正，多花一轮验证时间。

## 教训
对短暂弹出的 UI 状态，视觉模型的否定回答不可作为最终结论——用像素采样（扫描特定色带/位置）或日志（logcat、debugPrint）交叉验证，验证结果优先于模型判断。
