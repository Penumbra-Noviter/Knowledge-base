# 主题色 import 期冻结（初始化时序类 bug 代表）

## 症状
模块顶层 `_SIGNAL_TO_COLOR` 在 import 期调 `get_color()`，颜色冻结成 light 主题。T-01 处理过一次，**C1 又复发**。

## 根因
`get_color()` 的返回值依赖运行时主题状态，而模块导入发生在运行时状态建立之前 —— **把「运行时的值」在 import 期当常量固化**。

## 代价
同一 bug 复发两次，单靠修堵不住。

## 教训
① 运行时状态绝不进模块顶层；② 同根 bug 复发说明必须上**结构性防复发**，而不是再修一次。

## 防复发（惯例：开工预检时对照执行，无需勾选；动作项见条目内去向）
AST 静态检查：模块顶层禁止调 `get_color()`。同类：日志 handler 必须先于目录创建（见 [[空环境首启即崩]]）、`DATA_DIR.mkdir` 顺序钉死。
