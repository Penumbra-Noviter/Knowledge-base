# 识图兜底链：空内容必须判失败

## 症状
`qwen-image-2.0` / `qwen-image-2.0-2026-03-03` 做识图时，DashScope 兼容层返回 HTTP 200 但 `message.content` 为空（仅空壳 JSON）——旧脚本把任何非 4xx 响应当成功，输出原始 JSON 当结果。

## 根因
qwen-image 系列是**文生图**模型，不支持图像理解输入；OpenAI 兼容层对它返回 200 空响应而非报错，成功判定只看状态码就漏过了。

## 教训
1. 兜底/重试链的"成功"判定必须校验**内容非空**，不能只看 HTTP 状态码；
2. 模型选型先确认能力方向（理解 vs 生成），名字带 image 的不一定能识图；额度兜底链应只放实测可用的模型（当前链：qwen3.7-flash → qwen3.7-flash-2026-07-15 → qwen3.5-omni-plus）；
3. 失败日志要带模型名和原因，方便定位哪个模型、为什么失败。

## 防复发
- [x] vision.js 空内容判失败已实现（失败继续下一个，全部失败 exit 1）
- [x] 新增兜底模型先实测识图再入链
- 环境变量：`VISION_MODELS`（逗号分隔自定义列表）/ `VISION_MODEL`（单独指定主模型）
