# spike 有界任务子代理连续故障时主会话直接执行

## 现象

批次 13 波 3 三个 spike 并行派发 Prototype 子代理：S-C2 首派+重派均空返回（`Model returned no text…`），S-C6 首派亦空返回——同批 3 次基础设施故障。S-C2 重派仍失败后，主会话直接执行：合成 ITT 数据 + 纯 Python 统计（分位数距离/KS），一个脚本 + 一次运行即产出完整结论，无损耗。

## 判定规则

spike 类**有界验证任务**（合成/模拟数据、纯标准库、产出 .scratch 脚本+报告、不碰产品代码）具备「主会话直做成本 ≈ 子代理成本」特征：
- 子代理故障重派仍失败（同一任务 2 次空返回）→ 不再第三次派发，主会话降级直做；
- 直做前盘资产（worktree/stash/.scratch 半成品）确认无残留——本批次两次故障均零残留；
- 大范围多工单实现类任务（Implement）不适用此降级——上下文重量差异大，仍走重派/交接。

## 适用边界

- 适用：spike 机制验证、单文件实验、审计脚本（主会话可直写直跑）；
- 不适用：多文件 TDD 实现、需要连续多轮探索的任务——主会话上下文预算有限，降级会挤占编排空间。
